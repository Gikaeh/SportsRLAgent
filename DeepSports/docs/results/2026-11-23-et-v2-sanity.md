# et-v2 phase 1: data sanity checks on the Odds API history (lines only)

Written 2026-11-23, after the historical pull and **before any grading**: the checks of the pre-registration's
"Data sanity checks" section (`2026-11-23-et-v2-preregistration.md`, commit `3970720`). Only lines were read: the
2,916 cached snapshots and, from the warehouse (read-only), games **without** scores, teams, and the ESPN
opening/closing totals. No score, final total, result, win/loss or CLV was loaded, and no candidate was scored.

Code: `src/deepsports/analysis/et_v2_lines.py` (snapshot for a game day and time, per-book totals, event ->
ESPN `game_id` matching, agreement summary, the 60% rule; tests `tests/test_et_v2_lines.py` on a trimmed real
snapshot). Scripts and outputs: `/Volumes/ExFATStorag/DeepSports/work/et-v2-2026-11-23/` (`extract_lines.py`,
`sanity.py` -> `sanity_run2.json`, `diag_unmatched.py`).

## Data
- `basketball_ncaab`, markets `totals,spreads`, 10 books (betmgm, betonlineag, betrivers, bovada, draftkings,
  espnbet, fanduel, lowvig, pinnacle, williamhill_us); request times `-1@15:00`, `-1@18:00`, `-1@21:00` (= T),
  `0@09:00` PT for every ESPN game day of 2021-22 .. 2025-26. 2,916 files, 2,916 ledger rows, none empty.
- Games = D1 (both teams listed), regular + postseason, not postponed/canceled: 5,404 / 5,558 / 5,612 / 5,644 /
  5,633. Two game days have no files (2021-12-24, 2024-12-24; 1 D1 game each).
- **In-play quotes:** every snapshot also lists games already under way (66,271 book x total rows). Only events
  with `commence_time` after the snapshot time are used (`book_totals` drops the rest); scoring must do the same.
